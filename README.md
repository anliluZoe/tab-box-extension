# 标签页管家

一个帮你管理大量标签页的 Chrome 扩展（Manifest V3），解决"标签页开太多、找不到、不知道该关哪个"的问题。

## 功能

1. **按域名分组**：一键把每个窗口内相同域名的标签页合并成浏览器原生标签组（自动以域名命名、配色稳定），也可以一键解散所有分组。
2. **快速搜索**：在弹窗里按标题、网址或域名搜索所有窗口中已打开的标签页，点击即可跳转过去。默认快捷键 `Alt+T` 打开弹窗。
3. **访问统计与清理**：
   - 自动统计每个网页**今天被点开的次数**（切换到该标签页、页面导航完成都会计数），以及最后一次活跃时间，数据保留 7 天。
   - 列表支持按"访问最少优先"或"最久未用优先"排序，可只看"今日未访问"的标签页。
   - 底部按钮可一键关闭今日未访问的标签页（自动跳过固定标签页和当前标签页，关闭前会确认）。

## 安装（开发者模式加载）

1. 打开 Chrome，访问 `chrome://extensions/`。
2. 打开右上角的**开发者模式**开关。
3. 点击**加载已解压的扩展程序**，选择本项目文件夹。
4. 建议把扩展图标固定到工具栏，方便随时打开。

Edge 同理：在 `edge://extensions/` 中加载即可。

## 说明

- 所有统计数据只保存在本地（`chrome.storage.local`），不会上传到任何服务器。
- 访问次数按"当天"统计，跨天自动归零；历史数据超过 7 天自动清理。
- 刚安装时所有标签页的次数都是 0，使用一段时间后统计才有参考价值。

## 文件结构

- `manifest.json`：扩展配置（MV3）
- `background.js`：后台 Service Worker，负责记录访问次数和最后活跃时间
- `popup.html` / `popup.css` / `popup.js`：弹窗界面（搜索、分组、统计、清理）
