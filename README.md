# 标签页管家

一个帮你管理大量标签页的浏览器扩展（Manifest V3），同时支持 **Google Chrome** 与 **Microsoft Edge**（Chromium 内核）。

## 功能

1. **按域名分组**：弹窗里按域名收拢显示；默认开启**自动分组**，新开同域名标签页会自动并入标签组。
2. **自动去重**：默认开启。出现相同网址时会关掉更早打开的标签页，保留刚打开的那一个。
3. **快速搜索**：按标题 / 网址 / 域名搜索；`Alt+T` 打开，`↑↓` 选择，回车跳转。
4. **访问统计与清理**：统计每天点开次数，可按「访问最少 / 最久未用」排序，并一键关闭重复页或今日未访问的标签页。
5. **右键快捷入口**：在网页上右键可看到「标签页管家」子菜单，直接分组、关重复、关同域名标签页等。

## 安装（务必选对文件夹）

加载时选择的文件夹里，**必须能直接看到 `manifest.json`**。正确路径示例：

`D:\learning\brower-extension`

不要选上一级的 `learning`，也不要选里面的某个子文件。

### Microsoft Edge

1. 地址栏打开：`edge://extensions/`
2. 打开左下角 **开发人员模式**
3. 点击 **加载解压缩的扩展**
4. 选择包含 `manifest.json` 的项目文件夹（见上）
5. 若仍失败：看页面顶部红色错误提示，或点扩展卡片里的「错误」查看原因

### Chrome

1. 打开 `chrome://extensions/`
2. 打开右上角 **开发者模式**
3. 点击 **加载已解压的扩展程序**
4. 选择同一项目文件夹

## 说明

- 数据只存在本地，不会上传。
- 刚安装时访问次数都是 0，用一段时间后才有参考价值。
- 若标签组 API 不可用，「按域名分组」按钮会自动禁用，搜索和统计仍可用。
