## 3. UI 设计规范

### 3.1 整体设计风格

Quick Search 必须与浏览器扩展 Tab Box 保持一致的视觉风格和设计语言，不应设计成独立的第三方工具界面。

设计要求：

- 沿用插件现有的颜色体系、字体、圆角、边框、阴影和间距规范。
- 沿用现有的图标风格和组件样式。
- 搜索面板保持简洁、轻量，与 Tab Box 的整体视觉保持一致。
- 不引入与插件现有 UI 不一致的装饰性元素。
- 支持亮色和暗色主题，主题变化与插件保持同步。

### 3.2 搜索面板布局

- 面板显示在当前网页视口中央。
- 使用插件现有卡片风格和圆角规范。
- 面板宽度建议 480～560px，最大高度约 480px。
- 页面背景增加轻微半透明遮罩，突出搜索面板。
- 搜索输入框、结果列表和底部操作提示保持清晰的层级关系。
- 结果列表独立滚动，搜索框和底部操作栏固定。

### 3.3 组件样式

| 组件 | 设计要求 |
|---|---|
| 搜索框 | 沿用插件现有输入框样式，突出输入焦点 |
| 搜索结果 | 沿用现有列表项和卡片样式 |
| Favicon | 统一尺寸，保持视觉对齐 |
| 选中状态 | 使用插件现有主题强调色 |
| 搜索关键词 | 使用主题强调色高亮 |
| 操作提示 | 使用次级文字颜色 |
| 遮罩层 | 轻量半透明，不影响整体体验 |

### 3.4 交互视觉状态

需要设计以下状态：

- 默认状态：显示搜索框和最近访问的 Tab。
- 输入状态：实时过滤，关键词高亮。
- 选中状态：当前键盘选中项有明显背景反馈。
- 空结果状态：显示简洁的无结果提示。
- 加载状态：数据加载时显示轻量 Loading。
- 关闭状态：支持轻量淡出动画。

### 3.5 样式隔离

- 使用 Shadow DOM 隔离网页 CSS。
- 插件样式变量独立维护。
- 尽量复用 Tab Box 已有的 Design Tokens。
- 不直接继承宿主网页的字体、颜色和按钮样式。
- 主题配置与 Tab Box 共用，避免两套样式配置产生偏差。
