# Tab Box — Quick Search 设计方案

## 1. 产品定位与入口

Quick Search 是 Tab Box 的全局快捷搜索面板：在任意网页上按快捷键，直接搜索并跳转到已打开的标签页或已收藏的书签，不需要先打开扩展弹窗。

定位分工：

- **Popup（弹窗）**：整理工作区，负责分组、去重、批量关闭、批量收藏、书签管理。
- **Quick Search（快捷面板）**：只做「找到并打开」。轻量、即时、不打断当前页面。

入口：

| 入口 | 行为 |
|---|---|
| 快捷键 `Alt+K`（Mac 为 `Option+K`） | 在当前网页打开 Quick Search 面板 |
| 右键菜单「标签盒 → 快速搜索」 | 同上 |
| 无法注入脚本的页面（`chrome://`、扩展商店、PDF 阅读器） | 在独立小窗口中打开同一套搜索面板，关闭窗口即退出 |

快捷键可在 `chrome://extensions/shortcuts`（Edge 为 `edge://extensions/shortcuts`）中修改。

## 2. 功能与交互

### 2.1 数据源切换

面板顶部提供两个并列的 Tab：

- **标签页**：默认选中，打开面板后第一眼看到的就是当前打开的网页。
- **书签**：手动切换后进入书签搜索，搜索范围是全部书签，而不是某个文件夹。

切换方式：

- 点击顶部 Tab。
- 键盘按 `Tab` 在「标签页 / 书签」之间来回切换。

切换数据源时保留已输入的关键词，方便用同一个关键词在两个来源中对照查找；搜索框始终保持焦点。每次重新打开面板都回到「标签页」，不记忆上次的数据源。

### 2.2 搜索规则

| 能力 | 标签页搜索 | 书签搜索 |
|---|---|---|
| 搜索标题 | 支持 | 支持 |
| 搜索网址 | 支持 | 支持 |
| 搜索域名 | 支持 | 支持 |
| 搜索文件夹路径 | 不需要 | 支持 |
| 大小写不敏感 | 支持 | 支持 |
| 多关键词（空格分隔，需同时命中） | 支持 | 支持 |
| 关键词高亮 | 支持 | 支持 |
| 搜索范围 | 所有窗口的 http/https 标签页 | 全部书签 |

匹配优先级（从高到低）：标题开头 > 标题包含 > 域名开头 > 域名包含 > 文件夹包含（仅书签）> 网址包含。同分时按最近使用 / 最近添加排序。

### 2.3 结果与打开

- 无关键词时：标签页按最近访问排序，书签按最近添加排序，方便直接选最近用过的那一个。
- 有关键词时：按匹配优先级排序，最多渲染 100 条；超出时摘要显示「100 / 总数」，继续输入即可缩小范围。
- 标签页结果展示 favicon、标题、域名和最近访问时间；当前所在标签页带「当前」标记。
- 书签结果展示 favicon、标题、网址和所属文件夹路径。
- 打开标签页：切换到该标签页，并把所在窗口带到前台。
- 打开书签：在当前窗口新建标签页打开。
- 当前标签页被再次选中时，只关闭面板。

### 2.4 键盘操作

| 按键 | 行为 |
|---|---|
| `↑` / `↓` | 选择上一条 / 下一条 |
| `PageUp` / `PageDown` | 快速移动 5 条 |
| `Enter` | 打开当前选中项 |
| `Tab` | 切换「标签页 / 书签」 |
| `Esc` | 关闭面板 |
| 输入任意字符 | 实时过滤并高亮 |

面板打开期间按键不会传递给宿主网页，避免触发网页自身的快捷键。

### 2.5 界面状态

- **默认状态**：显示两个数据源 Tab、搜索框和最近访问的标签页。
- **输入状态**：实时过滤，关键词高亮。
- **选中状态**：键盘或鼠标选中的条目有明显背景与描边反馈。
- **加载状态**：数据读取时显示轻量 Loading，两个 Tab 上的数量显示为「…」。
- **空结果状态**：区分「没有打开的标签页 / 还没有书签」与「没有匹配结果」；搜索无结果时提示换关键词。
- **错误状态**：数据加载失败时显示可点击的重试提示；打开失败时在摘要位置短暂提示，不关闭面板。
- **关闭状态**：遮罩点击、`Esc`、打开条目后关闭，带轻量淡出动画。

## 3. UI 设计规范

### 3.1 整体设计风格

Quick Search 必须与浏览器扩展 Tab Box 保持一致的视觉风格和设计语言，不应设计成独立的第三方工具界面。

设计要求：

- 沿用插件现有的颜色体系、字体、圆角、边框、阴影和间距规范。
- 沿用现有的图标风格和组件样式。
- 搜索面板保持简洁、轻量，与 Tab Box 的整体视觉保持一致。
- 不引入与插件现有 UI 不一致的装饰性元素。
- 支持亮色和暗色主题，主题变化与插件保持同步。

### 3.2 搜索面板布局

- 面板显示在当前网页视口中央。
- 使用插件现有卡片风格和圆角规范。
- 面板宽度建议 480～560px，最大高度约 480px。
- 页面背景增加轻微半透明遮罩，突出搜索面板。
- 搜索输入框、结果列表和底部操作提示保持清晰的层级关系。
- 结果列表独立滚动，搜索框和底部操作栏固定。

### 3.3 组件样式

| 组件 | 设计要求 |
|---|---|
| 搜索框 | 沿用插件现有输入框样式，突出输入焦点 |
| 搜索结果 | 沿用现有列表项和卡片样式 |
| Favicon | 统一尺寸，保持视觉对齐 |
| 选中状态 | 使用插件现有主题强调色 |
| 搜索关键词 | 使用主题强调色高亮 |
| 操作提示 | 使用次级文字颜色 |
| 遮罩层 | 轻量半透明，不影响整体体验 |

### 3.4 交互视觉状态

需要设计以下状态：

- 默认状态：显示搜索框和最近访问的 Tab。
- 输入状态：实时过滤，关键词高亮。
- 选中状态：当前键盘选中项有明显背景反馈。
- 空结果状态：显示简洁的无结果提示。
- 加载状态：数据加载时显示轻量 Loading。
- 关闭状态：支持轻量淡出动画。

### 3.5 样式隔离

- 使用 Shadow DOM 隔离网页 CSS。
- 插件样式变量独立维护。
- 尽量复用 Tab Box 已有的 Design Tokens。
- 不直接继承宿主网页的字体、颜色和按钮样式。
- 主题配置与 Tab Box 共用，避免两套样式配置产生偏差。

## 4. 技术实现

### 4.1 组成

| 文件 | 作用 |
|---|---|
| `quick-search.js` | 内容脚本：按需注入当前标签页，创建 Shadow DOM、渲染面板、处理搜索与键盘 |
| `quick-search.css` | 面板样式，作为独立样式表注入 Shadow Root |
| `quick-search.html` | 受限页面的独立承载页：加载同一套面板，关闭时自动关闭窗口 |
| `background.js` | 注入面板、提供标签页 / 书签数据、执行打开动作、处理快捷键与回退 |
| `manifest.json` | 声明命令、`_favicon` 资源与所需权限 |

按下快捷键或点击右键入口时，Service Worker 先尝试向当前标签页发消息；若页面还没有面板脚本（首次使用、扩展刚更新、页面刚加载），则通过 `chrome.scripting.executeScript` 注入 `quick-search.js` 后重试。面板不会提前注入，也不在网页中常驻。

### 4.2 数据流

内容脚本无法直接访问 `chrome.tabs` 和 `chrome.bookmarks`，因此：

1. 面板打开时向 Service Worker 请求两个数据源。
2. Service Worker 分别执行 `chrome.tabs.query({})` 和 `chrome.bookmarks.getTree()`，返回精简后的数据：
   - 标签页：id、窗口 id、标题、网址、最近访问时间、是否当前、favicon。
   - 书签：id、标题、网址、文件夹路径、添加时间。
3. 面板在本地完成过滤、排序和高亮，输入时不产生额外消息，保证输入响应。
4. 打开条目时再向 Service Worker 发送一次动作消息，由 Background 调用 `chrome.tabs.update` / `chrome.tabs.create` / `chrome.windows.update`。

### 4.3 主题与多语言

- 主题读取 `chrome.storage.local` 的 `prefs.theme`，与 Popup 共用同一配置；`system` 时跟随 `prefers-color-scheme`，并监听变化实时更新。
- 文案全部走 `chrome.i18n`，启用 `__MSG_` 资源，中英文与界面其他部分保持一致。

### 4.4 权限说明

| 权限 | 用途 |
|---|---|
| `tabs` | 读取标签页标题、网址、最近访问时间 |
| `bookmarks` | 读取全部书签与文件夹路径 |
| `favicon` + `_favicon/*` | 本地读取书签图标，不发起网络请求 |
| `storage` | 同步主题配置 |
| `activeTab` + `scripting` | 在按下快捷键 / 点击右键入口时，向当前标签页按需注入面板脚本 |
| `contextMenus` | 提供右键入口 |

扩展不声明全站 host 权限，也不在页面中常驻内容脚本；不新增任何网络请求。

## 5. 边界与限制

- `chrome://`、`edge://`、扩展商店、PDF 阅读器等页面禁止注入内容脚本，此时快捷键改为在独立小窗口中打开同一套面板，关闭窗口即退出。
- 标签页搜索只覆盖 http/https 页面；`javascript:` 书签不展示，避免无法打开。
- 单次最多渲染 100 条结果，避免大量书签时卡顿；输入关键词继续缩小范围。
- 书签 favicon 通过浏览器本地缓存读取，若页面 CSP 或缓存缺失导致加载失败，使用首字母色块兜底。
- 面板打开时不会修改宿主页面的滚动、字体或布局，仅通过事件拦截避免误触网页快捷键。

## 6. 验收标准

- [ ] 任意 http/https 页面按 `Alt+K` 能打开面板，焦点自动落在搜索框。
- [ ] 打开后默认显示「标签页」，顶部可切换到「书签」，切换后关键词保留。
- [ ] 标签页可按标题、网址、域名搜索；书签额外支持文件夹路径搜索。
- [ ] `↑` `↓` `Enter` `Esc` `Tab` 行为符合第 2.4 节。
- [ ] 当前标签页有「当前」标记，打开其他窗口的标签页时窗口被带到前台。
- [ ] 无结果、加载中、加载失败、打开失败均有对应提示。
- [ ] 亮色 / 暗色主题与 Popup 设置同步，且与宿主网页样式完全隔离。
- [ ] `chrome://` 等受限页面触发快捷键时，在独立小窗口中打开同一套面板，并可正常关闭。
