# Tab Box — 标签页与书签管理设计方案

## 1. 产品定位

Tab Box 从标签页管理工具扩展为浏览器网页管理工具，统一管理用户打开的标签页和收藏的书签。

核心模块：

- **Tabs：** 标签页管理
- **Bookmarks：** 书签管理

每个模块提供独立的 Search、自动去重和批量操作能力，共用 UI 组件和交互体系。

## 2. 整体 UI 结构

### 顶部模块切换

在 Popup 顶部增加模块切换：

- Tabs
- Bookmarks

切换模块后，搜索框、去重入口、列表和批量操作同步切换。

保留现有 Tab Box 的 Logo、主题颜色、字体、圆角和组件样式，不重新设计一套 UI。

### Tabs 模块

保留现有功能：

- 按域名分组展示标签页。
- 搜索标签页。
- 自动去重标签页。
- 批量选择和关闭标签页。
- 批量收藏到书签。

### Bookmarks 模块

新增功能：

- 搜索书签。
- 按文件夹浏览书签。
- 自动检测重复书签。
- 批量删除书签。
- 批量移动书签。
- 支持新建文件夹。

## 3. Search 设计

Tabs 和 Bookmarks 分别使用独立搜索数据源，但复用相同的搜索组件。

| 功能 | Tabs Search | Bookmarks Search |
|---|---|---|
| 搜索标题 | 支持 | 支持 |
| 搜索 URL | 支持 | 支持 |
| 搜索域名 | 支持 | 支持 |
| 搜索文件夹 | 不需要 | 支持 |
| 实时搜索 | 支持 | 支持 |
| 关键词高亮 | 支持 | 支持 |

书签搜索默认搜索全部书签，而不是只搜索当前文件夹。

## 4. 自动去重设计

两个模块分别提供独立的自动去重能力。

### Tabs Dedup

- 检测当前打开的重复标签页。
- 按 URL 分组。
- 默认保留一个标签页。
- 用户确认后批量关闭重复标签页。

### Bookmarks Dedup

- 扫描完整书签树。
- 按 URL 分组检测重复书签。
- 展示重复书签的名称和所属文件夹。
- 默认保留一个书签，其余标记为待删除。
- 用户可以调整删除选择。
- 确认后批量删除。

### 去重交互统一

两个模块采用相同的流程：

1. 开始检测。
2. 按 URL 分组展示重复结果。
3. 默认选中建议清理的项目。
4. 用户确认清理。
5. 展示清理结果。

注意：检测和删除分离，不自动删除用户书签或关闭标签页。

## 5. 批量操作

### Tabs

- 批量选择标签页。
- 批量关闭。
- 批量收藏到指定书签文件夹。

### Bookmarks

- 批量选择书签。
- 批量删除。
- 批量移动到其他文件夹。
- 支持新建目标文件夹。

批量收藏和移动均支持逐级选择书签文件夹。

## 6. 页面结构

建议采用模块切换 + 内部页面切换的结构：

- `TabsView`：标签页列表。
- `BookmarksView`：书签列表。
- `SearchView`：搜索结果。
- `DedupView`：统一去重结果页面，根据当前模块加载不同数据。
- `BookmarkFolderView`：选择目标文件夹。
- `ResultView`：批量操作结果。

Popup 内部切换页面，不使用嵌套 Modal。

## 7. 技术实现

### 数据来源

| 模块 | API |
|---|---|
| Tabs | `chrome.tabs` |
| Bookmarks | `chrome.bookmarks` |

### 组件复用

统一复用：

- SearchInput
- GroupList
- SelectionBar
- DedupResultList
- ConfirmView
- ResultView

数据获取和操作逻辑通过不同的数据适配器实现，避免混合 Tabs 和 Bookmarks 的业务逻辑。

### 数据安全

- 删除前再次确认目标是否存在。
- 单条操作失败不影响其他项目。
- 记录每条操作结果。
- 支持失败项重试。
- 默认不自动删除。

## 8. 设计原则

1. 保留现有 Tab Box 的视觉风格。
2. 两个模块的相同能力保持一致的交互。
3. 不同数据对象使用独立的数据源和业务逻辑。
4. 优先复用现有组件，不重复开发。
5. Popup 空间有限，复杂操作采用内部页面切换。
6. 先保证搜索、去重、批量操作体验，再逐步扩展书签管理能力。

## 9. 开发优先级

**P0：基础能力**
- 顶部 Tabs / Bookmarks 切换。
- 书签列表与文件夹浏览。
- 书签搜索。
- 书签自动去重。

**P1：批量操作**
- 批量收藏标签页。
- 批量删除书签。
- 批量移动书签。

**P2：后续扩展**
- 书签导入导出。
- 失效链接检测。
- 书签文件夹整理。
- 更多智能整理能力。
