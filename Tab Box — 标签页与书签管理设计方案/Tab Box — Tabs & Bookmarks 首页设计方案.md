# Tab Box — Tabs & Bookmarks 首页设计方案

## 1. 产品定位

将 Tab Box 从标签页管理工具扩展为浏览器网页管理工具，统一管理：

- **Tabs：** 当前打开的网页。
- **Bookmarks：** 浏览器收藏的网页。

两个模块独立管理数据，共用搜索、列表、选择、去重等交互组件。

## 2. 首页整体布局

不增加独立的 Tabs / Bookmarks 导航栏，直接在现有顶部品牌区域增加模块切换操作。

页面结构：

1. 顶部品牌区
2. 搜索框
3. 功能控制区
4. 数量统计和排序
5. 内容列表
6. 底部操作栏

### 顶部品牌区

左侧：
- 固定 Tab Box Logo。
- 动态标题。
- 动态功能说明。

右侧：
- 使用 `arrow-left-right` 双向箭头图标。
- 点击直接切换 Tabs / Bookmarks。
- 不使用下拉菜单。
- 保持现有按钮尺寸、圆角和主题颜色。

不同模块的标题：

| 模块 | 标题 | 说明 |
|---|---|---|
| Tabs | 标签页管理 | 管理当前打开的网页 |
| Bookmarks | 书签管理 | 整理和管理已收藏的网页 |

默认打开 Tabs，切换后记住用户上次选择的模块。

## 3. Tabs 模块

保留现有功能和布局，不改变原有用户习惯。

### 搜索
- 实时搜索标题、URL、域名。
- 支持关键词高亮。

### 功能控制区
- 按域名分组。
- 自动去重。

### 统计与排序
- 当前标签页数量。
- 闲置标签页数量。
- 重复标签页数量。
- 支持现有排序方式。

### 列表
- 保留现有域名分组卡片。
- 支持单条和整组选择。
- 支持关闭标签页。
- 支持批量收藏。

## 4. Bookmarks 模块

新增书签管理工作空间，沿用 Tabs 的整体布局和视觉风格。

### 搜索
- 搜索全部书签。
- 支持标题、URL、域名、文件夹名称搜索。
- 实时搜索和关键词高亮。

### 功能控制区
- 文件夹筛选。
- 书签自动去重。

### 统计与排序
- 书签总数量。
- 文件夹数量。
- 支持最近添加、名称等排序方式。

### 列表
- 默认展示全部书签。
- 文件夹和书签分开展示。
- 文件夹点击后进入下一层。
- 支持返回上级目录。
- 书签展示 favicon、标题和 URL。
- 支持单条和批量选择。

### 批量操作
- 新建文件夹。
- 批量移动书签。
- 批量删除书签。

## 5. 自动去重

两个模块分别提供独立的去重功能，但复用相同的交互组件。

### Tabs Dedup
- 检测当前打开的重复标签页。
- 按 URL 分组。
- 默认保留一个标签页。
- 用户确认后批量关闭重复项。

### Bookmarks Dedup
- 扫描完整书签树。
- 按 URL 分组检测重复书签。
- 展示书签名称和所属文件夹。
- 默认保留一个，其余标记为待删除。
- 用户可以调整删除选择。
- 用户确认后批量删除。

### 统一交互流程

1. 开始检测。
2. 展示重复结果。
3. 默认选中建议清理的项目。
4. 用户确认清理。
5. 展示清理结果。

不自动删除，所有清理操作都需要用户确认。

## 6. 批量收藏

在 Tabs 模块中增加批量收藏能力：

1. 进入选择模式。
2. 勾选需要收藏的网页。
3. 点击批量收藏。
4. 选择 Chrome 书签文件夹。
5. 确认收藏。
6. 展示成功、跳过和失败数量。

重复 URL 默认跳过，不覆盖已有书签。

## 7. 组件复用

两个模块共用：

- `SearchInput`
- `GroupList`
- `BookmarkList`
- `SelectionBar`
- `DedupResultList`
- `ConfirmView`
- `ResultView`

不同模块使用独立数据源和操作逻辑。

## 8. 交互规则

- 切换模块不增加新的页面层级。
- 两个模块分别保留搜索词、排序和滚动位置。
- 切换模块时退出当前选择模式。
- Popup 关闭后不保留未完成的选择状态。
- 删除和批量操作前进行确认。
- 单条操作失败不影响其他项目。

## 9. 开发优先级

### P0：基础功能
- 顶部模块切换。
- Tabs 原有功能保持不变。
- 书签列表与文件夹浏览。
- 书签搜索。
- 书签自动去重。

### P1：批量操作
- Tabs 批量收藏。
- Bookmarks 批量删除。
- Bookmarks 批量移动。

### P2：扩展能力
- 书签导入导出。
- 失效链接检测。
- 书签文件夹整理。

## 10. 设计原则

1. 保留 Tab Box 现有视觉风格。
2. 不增加独立的 Tabs / Bookmarks 导航栏。
3. 使用右上角 `arrow-left-right` 直接切换模块。
4. 两个模块共享 UI 组件，但业务逻辑独立。
5. 优先复用现有功能，避免重复开发。
6. 保持 Popup 简洁，复杂操作使用内部页面切换。
