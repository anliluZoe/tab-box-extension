Privacy Policy — 标签盒 (Tab Box)

Browser extension for Microsoft Edge and Google Chrome · Last updated: November 4, 2026

1. Summary

标签盒 (Tab Box) is a tab-management extension. It does not collect, transmit, sell or share any personal data. All data the extension works with stays inside your browser on your own device. There is no account, no analytics, no advertising, and no tracking of any kind.

2. What the extension stores, and where

The extension uses the browser's local extension storage (chrome.storage.local). This storage is private to the extension on your device. It is never uploaded, never synchronized to a cloud account, and is not readable by websites.

  • Your settings — two on/off switches (automatic grouping, automatic de-duplication). Kept until you change them or uninstall the extension.
  • Tab activity records — for pages you visit, the page address, how many times you opened it today, and when you last used it. These records exist only so the "close tabs unused for 1/2/3 days" feature can work. They are automatically deleted after 7 days.

The extension does not store page content, form data, passwords, cookies, bookmarks, download history, or any file from your device.

3. What the extension reads

To list, group and clean up tabs, the extension reads the metadata of your open tabs: title, address (URL), favicon, pinned state, tab-group membership and last-access time. This information is processed in memory and, for the activity records described above, stored locally. It is never sent anywhere else. The extension does not inject scripts into web pages and does not read the content of the pages you visit.

4. Network requests

The extension makes exactly one kind of network request, and only when you explicitly click "Check for updates": it asks the public GitHub API (https://api.github.com) for the latest release of the extension's own repository, in order to compare version numbers. This request contains no personal data — no identifiers, no browsing history, no tab information. It is never made on install, at browser startup, or while you browse.

If a newer version is found, your browser opens the public GitHub release page so you can download it manually. The extension itself never downloads or installs anything.

5. Sharing and disclosure

We do not sell, rent, trade or share data with anyone. There are no third-party SDKs, no remote servers operated by the developer, and no data brokers involved. Because the developer never receives your data, there is nothing to disclose to third parties.

6. Permissions and why they are needed

  • tabs — read the list of open tabs so they can be shown in the popup, grouped by website, and closed when duplicate or long-unused.
  • tabGroups — create, name, colour and update tab groups; merge tabs from the same website into one group.
  • storage — keep your two settings and the 7-day activity records on your device (required because the extension's background worker restarts).
  • contextMenus — add the "标签盒" right-click submenu as a shortcut to the same actions available in the popup.
  • Host permission https://api.github.com/* — allow the optional update check described in section 4.

7. Children

The extension is a general-purpose utility. It is not directed at children, and it does not knowingly collect information from anyone, including children under 13.

8. Your control and deletion

You can remove the stored activity records at any time from the extension's popup, or open edge://extensions / chrome://extensions and clear the extension's data. Uninstalling the extension deletes all data it stored. Since no data is held by the developer, there is no separate deletion request to make.

9. Changes to this policy

If a future version of the extension changes how data is handled, this page will be updated before that version is published, and the "Last updated" date above will change. Material changes will also be noted in the extension's release notes.

10. Contact

Questions about this policy or about privacy in the extension can be raised at github.com/anliluZoe/brower-extension/issues.

隐私政策 — 标签盒

适用于 Microsoft Edge 与 Google Chrome 的浏览器扩展 · 最后更新：2026 年 11 月 4 日

一、概述

标签盒是一款管理标签页的浏览器扩展。它不收集、不上传、不售卖、不共享任何个人数据。 扩展处理的所有数据都只保存在你本机浏览器的扩展存储中。没有账号体系，没有统计分析，没有广告， 没有任何形式的追踪。

二、保存了什么，保存在哪里

扩展只使用浏览器提供的本地扩展存储（chrome.storage.local）。该存储仅本扩展可读， 位于你自己的设备上，不会上传，不会同步到云账号，网站也无法读取。具体包括：

  • 你的设置：两个开关（自动分组、自动去重），直到你修改或卸载扩展为止。
  • 标签页活跃记录：访问过的页面地址、当天打开次数、最近使用时间。这些记录仅用于实现 「关闭近 1/2/3 天未访问的标签页」功能，超过 7 天自动删除。

扩展不保存网页内容、表单数据、密码、Cookie、书签、下载记录或设备上的任何文件。

三、读取了什么

为了列出、分组和清理标签页，扩展会读取已打开标签页的元数据：标题、网址、图标、是否固定、 所属标签组、最后访问时间。这些信息只用于本地处理（活跃记录按上节说明在本地保存），不会发送到任何地方。 扩展不会向网页注入脚本，也不会读取网页内容。

四、网络请求

扩展只有一种网络请求，且仅在你主动点击「检查更新」时发起：向公开的 GitHub API （https://api.github.com）查询本扩展自己仓库的最新 Release，用于比较版本号。 该请求不包含任何个人数据——没有标识符、没有浏览记录、没有标签页信息。安装时、浏览器启动时、 浏览网页时都不会发起请求。若发现新版本，浏览器会打开公开的 GitHub Release 页面由你手动下载， 扩展本身不下载、不安装任何东西。

五、共享与披露

本扩展不向任何人出售、出租、交易或共享数据。没有第三方 SDK，没有开发者自建服务器，不涉及 任何数据中间商。由于开发者根本收不到你的数据，也就不存在向第三方披露的可能。

六、权限用途

  • tabs：读取已打开标签页列表，用于弹窗展示、按域名分组、关闭重复或长期未用的标签页。
  • tabGroups：创建、命名、上色和更新标签组，把同域名标签页并入同一组。
  • storage：在本机保存两个设置项和 7 天活跃记录（扩展后台会被浏览器重启，必须持久化）。
  • contextMenus：添加「标签盒」右键子菜单，作为弹窗中已有功能的快捷入口。
  • 主机权限 https://api.github.com/*：用于第四节所述的检查更新功能。

七、儿童

本扩展是通用工具，不面向儿童，也不会有意收集任何人的信息，包括 13 岁以下儿童的信息。

八、你的控制与删除

你可以随时在扩展弹窗中清除活跃记录，或在 edge://extensions（Chrome 为 chrome://extensions）中清除该扩展的数据。卸载扩展会删除其保存的全部数据。 由于开发者不持有任何数据，无需另行提出删除请求。

九、政策变更

若未来版本改变数据处理方式，本页面会在该版本发布前更新，并同步修改上方的「最后更新」日期； 重要变更也会写进扩展的更新日志。

十、联系方式

关于本政策或扩展隐私问题，可在 github.com/anliluZoe/brower-extension/issues 提出。
